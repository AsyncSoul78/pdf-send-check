# Before you send a PDF

A short list to go through before a signed form, a CV or a contract leaves your computer. Each point matches a line of `pdf-send-check` output.

## Open the copy you are about to send

- [ ] Open the saved file, not the one still open in the editor. Scroll through every page.
- [ ] The page count is what you expect. Extra blank pages often come from a table or picture that did not fit.
- [ ] Bookmarks, if the file has them, open the right pages.

## Marks and signatures

- [ ] Your signature and notes are in the saved copy, not only on screen.
- [ ] If the marks are annotations (`Ink`, `FreeText`, `Stamp`, highlights), the recipient can move or delete them. For a signed form you usually want them to be part of the page.
- [ ] Fillable fields: decide whether the recipient should still be able to change the values.

## Hidden content

- [ ] "saved 2 times" or more: the earlier version is still inside the file. If you removed something private, save a fresh copy (print to PDF or export again) instead of saving over the old one.
- [ ] Attached files: you know what they are and the recipient needs them.
- [ ] Script actions: there is a reason for them. Some mail servers reject PDFs that contain scripts.

## Document info

- [ ] Author: the name you want the recipient to see. Converted files take it from the source document, so change it there before converting.
- [ ] Title: not an old working name such as "draft 3" or "copy of copy".

## Last step

- [ ] File name: clear to the recipient, without "final_final" or internal codes.
- [ ] Size: fits the mail or upload limit (often 10 to 25 MB).
